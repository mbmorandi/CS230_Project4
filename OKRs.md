# OKRs for Project 4

NOTE: You do not have to use these KRs. you can create new ones or modify the ones below.

1. Velocity & Low Friction (User Experience)

• Objective: Make instant academic file sharing the fastest and most seamless tool on campus. (Azhan)
	• KR 1: Maintain a 1-click sharing flow (zero interstitial screens or pop-ups from upload to generated link).
	• KR 2: Achieve an average upload-to-link-generation speed of under 2.5 seconds for files up to 50MB.
	• KR 3: Keep the link expiration failure rate (links failing to auto-delete after the set time/downloads) at 0%.

2. The Conversion Flywheel (Turning Free Utility into Registered Users)

• Objective: Leverage anonymous sharing as our primary engine for new user acquisition.
	• KR 1: Convert 12% of anonymous downloaders into registered users via contextual call-to-actions (e.g., "Save this to your permanent cloud library").
	• KR 2: Convert 8% of anonymous uploaders into account creators by offering advanced features (e.g., track view count, extend expiration date).
	• KR 3: Generate 15,000 new registered sign-ups directly originating from anonymous shared links.

3. Cost Control & Infrastructure Optimization (Misha)

• Objective: Scale instant sharing aggressively while maintaining strict capital efficiency.
	• KR 1: Cap the average hosting/bandwidth cost per anonymous transfer at less than $0.002.
	• KR 2: Automatically purge expired instant files within 5 minutes of expiration to keep server storage overhead below 2TB.
	• KR 3: Implement peer-to-peer WebRTC connections for 40% of local transfers (e.g., students in the same lecture hall) to bypass server bandwidth entirely.

4. Trust, Safety, & Spam Mitigation (High Risk Area)

• Objective: Prevent the anonymous gateway from being abused by spam, malware, or illicit content.
	• KR 1: Run automated virus and malware scans on 100% of anonymous uploads prior to link generation.
	• KR 2: Reduce the time to take down reported malicious or copyrighted anonymous links to under 15 minutes.
	• KR 3: Block 99.9% of automated script/bot uploads by implementing invisible, low-friction bot detection (e.g., turnstile or behavior analysis) without hurting real user speed.
